Which side are you testing?

Both sides share one test database and use the same sign-in. A packet sent from the intake, from any computer, appears in the office console within seconds, and the office's decisions show up under My submissions for the person who sent it.

Department administrator Intake Start a new appointment, reappointment, change or visa check. Generate the packet and send it to ATO. Open the intake › ATO office Console Work the queues: validate new submissions, route, return with notes, remind signers and file. Open the console ›

Tip: open both in side-by-side windows to watch a packet move.
